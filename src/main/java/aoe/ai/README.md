# aoe/ai — 玩家 AI

规则式玩家 AI 包。接口 `PlayerAi.tick(c game)` 每帧首在 paint/Timer 线程被调
（c.java 帧首 hook，`-Daoe.playerAi=<全限定类名>` 反射装载；装载失败/tick 异常
打 `[ai]` 日志并禁用，不影响游戏）。hook 在 onPaint 帧首，**不受 screenState
门控**——弹窗态（ss==2）下模拟停走但 AI 照样被调，AI 须自按 -7 关窗。

两个实现：`RuleBasedAi`（随机图，见下）与 `CampaignAi`（战役，见末节）。

## CampaignAi（战役，2026-09-04）

`-Daoe.playerAi=aoe.ai.CampaignAi` + `-Daoe.dev=campaign:N`（N=1..7 对应
missionIndex 0..6）。批跑：`tools/camloop.sh -m N -n 局数 -t 超时 -k`。
战役地图每局重掷（z=98 结算重掷种子），camloop 无需种子参数。
各关胜负条件：反汇编考证在 `docs/research/campaign-mission-scripts.md`
（工具 `tools/scriptdis.py`）。

- **战役机制教训**（都踩过坑，写代码前先读）：
  - 采集一载 = 102 tick 计时（任务字高字节倒数），期间写 slot[7]=0 = 清零
    重来——重发节流必须远大于 102t（escort v1 用 24t 永远砍不倒树）。
  - 单位占位（0x2xx）会盖住格下的资源/地形显示，扫描地图要避开或豁免。
  - 可走判据 = `(t & 0xFFF) == 0`（虚空 0x0/雾 0x8000/已探索 0x4000 都能走；
    雾下资源 0x83xx 低位非零=挡路）。
  - 战役敌 aiEnabled=false：守军不追远、不出击，只原地自动接敌——
    "守军最少优先+打了就跑+站桩回血"是拆建筑关的通关公式。
  - 站桩回血要 pos==tgt：撤退点必须按槽位散开（同点撤退互相占位永不回血）。
    回血速率 +1 HP/2t（tickUnits case 0：任务字 0 + pos==tgt + (tickCount&8)!=0，
    HP<255；全员 HP 上限 255）。
  - 塔/守军瞄准 = 槽序扫描（aimProjectiles/acquireTarget 都取射程内最低 slot，
    不取最近/最弱）——我方剑士 slot 0-4 < 攻城器 slot 10-16，近战进场即天然
    肉盾；单位战斗态不追人（tickUnits case 1 只对 slot[5] 格原地开火），贴身
    接敌=双方互锁（acquireTarget 双写）；被打会报复（resolveAttack 把受害者
    tgt 改写成攻击者位置——"守军不追击"只对未接敌成立）。
  - 伤害公式统一 攻<<4/甲：塔 64/甲 per 17t（Keep [46]=4）、投石机对甲2 目标
    112/发；单位拆建筑同式（resolveAttack case 256，建筑甲 [33+type]，HP 255）。
  - 通用"拆敌 TC 即胜"规则在战役 missionIndex≠0 被跳过（onThingDestroyed
    case 9）——#4 这类关只有脚本胜利一条路，rush 不可行。
  - 交存锚点 hdr[8]=TC/hdr[9]=伐木场/hdr[10-11]=采矿场；无 TC 关要伪造
    hdr[9] 到袋内空地，否则载满回送 orbit。
  - 敌开 AI 的运营关（#4）：逃命=102t 采集计时清零，敌露营矿线时一刀切
    逃命=收入归零——解法组合 = 塔位罩住矿线 + 塔圈内不逃 + 兵/塔资源
    排序（塔前兵帽 1，军费不能抢走塔的启动金）。

## RuleBasedAi

随机图（gameMode=0）Easy/Medium/Expert 通用。**2026-09-04 第六批起默认开
「迷雾诚实模式」**（`-Daoe.aiFog=0` 回退全图，ailoop `-f` 透传；`AOE_AIFOG=res|tc`
为消融诊断档）：只读已探索格（mapTiles 0x8000 位=唯一视野层，与渲染/小地图
可见性逐格一致，考证见 game-mechanics「迷雾与视野」）上的敌单位/建筑/资源，
禁读 hdr[1] 统计字段（军值/资源/人口/TC 位），敌 TC 位置靠侦察记忆。
成绩（诚实模式，ailoop -b -t 240，种子 1000+ n=10，1004 退化图跳过）：
**Easy 8/10+7/10（两批合并 15/20）；Medium 8/10+4/10（两批行为等价、合并
12/20——同种子跨批翻面剧烈，只信合并带）；Expert 1-2/10（四批 5/40）**。
全图对照（-f 实测 4/10，胜种子与 v56 完全一致=回退路径零失真）：
Easy/Medium/Expert 全图历史成绩 5/5、10/10、4/10。信息价值量化与消融见
`docs/research/rulebased-ai-medium-iteration.md`「信息收紧（第六批）」——
**全图挂的总价值 ≈ Expert +2.5-3 胜/10、Medium +2-4、Easy +1-2；没有任何单一
信息通道能独力补回 Expert 缺口（res 消融 2/10、tc 消融 1/10），硬约束是波 1 前
的探索速率（单位视野只有 3×3）**。

历史（全图时代 v56 定型 = v35 微操四件套 + 围城经济组件）：Expert 1000+ 4/10、
1010+ 1/10；Medium 1000+ 10/10、1010+ 10/10、2000+ 7/10；Easy 1000+ 5/5。
第五批结论：败局定性为"石/兵种帽死锁"，胜负的完美预测子 = 有没有建成
archery/smith。六颗常败种子（1002/1005/1006/1007/1009/1010）跨 v35-v56 未胜
=石贫图/近距 rush 图对 4 村民经济的可行性边界。

战略一句话：**塔防吸收敌方 all-in → 集结后反击拆敌 TC**（拆 TC 即胜）。拼经济
必输（敌 3.07×/8× 采集 vs 我方 4 村民硬上限 + pop 25），塔不占人口且完工计入
hdr[55] 军值（威慑敌 all-in 判定），是唯一的免费战力。

每 8 tick 决策一次，模块顺序（带 ★ 为第六批诚实模式新增）：

0. ★**信息层**：可见性过滤（evis：敌单位所在格已探索才进任何计数）；敌建筑
   扫描记忆敌 TC（`enemyTcMem`）与最近目击方向（`enemyHint`）；首波接触来向
   （`waveOrigin` = 新接触时离我 TC 最远的可见敌兵）。全图模式全部旁路。
0b. ★**侦察**：scout0（t5 优先，否则首个军事单位）走螺旋路点（TC 外扩正方形环，
   弧距 ≤3=视野无缝）；有接触来向改走射线（延长线反推+横向锯齿）；milCount≥6
   加 scout1（错开半圈）；威胁中 milCount≥3 保持侦察；卡死 300t 跳路点。
   敌 TC 未知时塔位降级为绕 TC 塔环（有来向则环序朝来向旋转），僵持 15k 后
   全军 HUNT 扫荡开图（路点不可达 1500t 无进展跳过）。
1. **态势扫描**：我方村民按 action/目标格归工种（木/金/石），军事计数量与价值
   （Σ(攻+甲)）；敌方计**可见**军值/军数（估值用我方同兵种数值），可见敌塔折
   "防御军值"。波次预测器仅全图模式启用（读 ehdr[55] 的只读遥测）。
2. **弹窗自关**：ss==2 时 `onKeyPress(-7)` 后返回（z=62/z=70 信息弹窗冻结世界，
   headless 无人关窗 = 永久 STALL，seed 1010 实测冻 27 万 tick）。
3. **军事**：
   - 敌兵进我方 TC 10 格（DEFEND_D2=100）→ 近战群令压上；弓兵/投石机停在
     入侵者朝防御锚点 3 格处开火（远程不送近战圈）；敌 t8 在 20 格内时远程优先点杀
     （投石机远程拆塔，近战无解——agent-operations §5.1/r29）。
     **塔援护（仅 Expert）**：敌兵贴近任一完工塔 6 格内同样触发 DEFEND——
     Expert ×8 波次会逐个拔掉外圈孤塔（v15 复盘：5 塔被白拆 4 座军队在旁观）；
     Medium 上同机制反而把军队拉离 TC 塔圈吃败仗（v16 实测 6/10），故按
     `aiGatherMultiplier >= 1024` 难度门控。
     **Expert 波 1 接战微操（v35 四件套，全在 expert 门内）**：① 环形拦截——
     近战钉在锚点朝敌 3 格塔火重叠区等接敌，不冲入侵者（冲锋=出圈被围殴）；
     ② 集火闪避——被敌攻击态锁定（敌 slot[5]==我格）的单位每决策横移一格
     （攻击按格结算，离格=敌装填清零重追），落点塔圈内优先，人数上限
     milCount/2；③ 投石机猎手——敌 t8 贴近塔/TC 10 格派 ≤2 快腿近战直取
     （塔对射射不过 t8），每决策重投；④ DEFEND 逐单位下令——攻击态/回血中/
     猎手/侦察兵单位不被 48t 群令重发打断装填。遥测：摘要行 `dodges=/hunts=`。
   - 残血（HP<100）回撤 TC 背敌侧站桩回血（0.5 HP/tick），HP>220 归队——
     消耗战里保老兵 = 省替换金，对 3.07× 产量的敌人是刚需（v11 关键胜率来源）。
   - 反击触发（需家门清净 + 敌 TC 已知）：敌主力被歼（可见峰值 ≥5 且现存 ≤1/3）
     / 碾压（军值 ≥130 且 ≥ 敌防御军值 4/3）/ 僵持兜底（t25000 后）/ **贴脸图闪击**
     （双方 TC ≤14 格：消耗战必输，兵力不劣直接上）/ ★**金竭突击 GOLDSTARVE**
     （金不可派且存量不够再训——与其坐耗等死不如搏拆 TC）。**Expert 反击门槛
     抬高**：≥10 兵且军值 ≥ 敌塔计入后的防御军值（7 兵反击=把家底送进敌塔环）。
     进攻中小股（≤3）反扑不撤，大股撤；1500 tick 无进展判定停滞撤回重整。
   - **进攻两阶段（v14）**：先全军集结到敌 TC 朝我 7 格（警戒圈 6 格外沿，
     顺带触发敌防御模式反扑空巢），到齐 2/3 或超时 700 tick 再一起扑敌 TC——
     兵种移速差 4 倍（投石机 256 vs 剑士 1024），群令直发=添油送死
     （v13 败局 2001/2006 复盘实锤）。
   - 互瞪僵局诱敌：t15000 后久无接触且敌蹲家 ≥10 兵 → 派最便宜的兵直扑敌 TC
     触发其防御模式反扑，喂给我方塔阵（§5.3 调虎离山；驻防群令会召回诱饵，
     靠每决策重投续上）。诚实模式需敌 TC 已知。
4. **村民**：闲置（action=0 且已到目标格；采集→交存→返矿全自动，§10 定论）
   与卡死（行军 300 tick 未动 → 目标拉黑 3000 tick）重派；配额 boot 期 2木1金，

   需石而石工为 0 时放宽抽调门槛）。敌兵贴脸 7 格 → 村民撤命，**v38 起 Expert、
   第六批起诚实模式全难度撤到"最近未蹲守同种资源格"直接复工**（逃命不失业；
   找不到才退 TC 另一侧）。
   ★**发现探针**：木或金整类无可派格时，前两个闲村民改派近环探路；全员在岗

   资源格打 camped 标记（滚动窗 1500t=敌走后才解禁，防两矿来回跳振荡环）；
   转移只派"比我 TC 离敌更远"的走廊外资源格（Expert 限定）。
   **纪律：村民配额/再平衡全是 +1 缓冲的阻尼收敛，不许做"严格收敛/急救抽调"——
   会与逃命链互激成震荡环（v18/v19/v22 三连败实锤，v18 单局 36 次 rebalance）。

   塔1 → 采矿场 → 塔2 → 铁匠铺 → 射箭场 → 塔3-5 → 房屋2-4 →

   （r26 验证的最优汇率防术；近距图钳到走廊 60% 内，别蹭进敌警戒圈）；
   ★敌 TC 未知时降级为绕 TC 塔环、有接触来向则朝来向旋转。

   v57 条件内赋值冲掉 anchor 吞掉整链的教训）**。

   22木/6金/16石；房 5 木=最便宜人口+仇恨海绵——人口帽被磨掉=金囤着变不成兵）。

   `queueUnitTraining` 只排同类型**第一座**建筑（c.java:6519 记录序扫描），
   第二兵营靠直写队列位（rec[+2]+=65536 + hdr[49]++ + hdr[66+t]++）。

   （金 ≥60）。产兵扣款在产出时，排多不亏但占人口名额。
8. **修塔（v44/v46，仅 Expert）**：最残的完工塔/TC（HP<245）派 ≤2 个最近
   满血（HP≥220）村民修理——走到受损建筑格自动进 action 4，~0.5 HP/tick/人
   且免费，1 人恰好抵消 1 剑士磨塔。修理工不参与逃命（否则敌兵贴脸 7 格的
   逃命规则每 8t 把修理工拽走），但 HP<200 即退役回逃命链（挨一刀就放——

## 已知边界

- seed 1004 型退化图（无可达金矿 + 敌 TC 被塔围死）：僵持，可接受（三难度同图同症）。
- 高方差近距 rush 种子：Medium 2000+ 区间仍有个位败场（最终复测 2004/2008）——
  敌 3.5-6k 到家时金收入上限是硬约束。
- Expert（×8 采集 + 每 tick 出兵 + 免费资源滴=敌村民数/1000t）：全图 40% 是规则式
  当前上沿；诚实模式 1-2/10——缺口在波 1 前的探索速率（单位视野 3×3 焊死信息
  天花板），不在战斗微操（第四批已证伪）也不在围城经济（第五批已定性）。
- **双方僵尸局**（诚实模式新增边界）：村民全灭 + 木=0 + 塔在场 → 不满足失败条件、
  产不出村民（训练要木），敌也磨不动塔 → 空转到墙钟 STALL（Medium 1006 两批
  连续实锤）。动作空间内无解（无市场无变卖）。
- 同一种子跨跑结果会翻（菜单导航墙钟相位）——诚实模式马拉松局放大该噪声
  （v62/v64 行为等价的 Medium 同批种子 8/10 vs 4/10）：只信多批合并带。
