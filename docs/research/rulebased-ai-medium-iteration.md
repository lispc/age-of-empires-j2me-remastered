# Medium 攻坚迭代笔记（2026-09-03）

## v1 基线（M1 报告）：Easy 13/15，Medium 0/3（~15-20k tick 败）
败因：敌 3.07× 经济 + 60 阈值早 all-in；我方出门半吊子触发敌 87.5% 反扑；投石机拆塔无解。

## v2 假设
- 投石机产自铁匠铺（case 8→建筑6，v1 在攻城工坊排队=永久静默失败）——铁匠铺=攻防升级+投石机双收益。
- 走廊阶梯塔前置到封建前（塔 1/2 在兵营后即建）；塔完工加 hdr[55] 军值可推迟敌 all-in。
- 防守反击：不主动进攻，敌主力峰值跌 1/3 后反击拆 TC（拆 TC=即胜）。
- 村民逃命（敌兵 7 格内撤 TC 另一侧）；小股骚扰（≤3）进攻中不回家。

## 实锤的引擎层现象（记录，不改本体）
- **弹窗冻结**：headless 下 z=70（新建筑首建）/z=62（升时代）信息弹窗无人按键 →
  screenState=2 永驻，onPaint default 分支不跑 = 模拟冻结，但 tickCount 每帧照走
  （++tickCount 在 onPaint 无条件段）。v4 起 AI 侧按 -7 自关，实证解冻。
- seed 1004：全图无可达金矿 + 敌 TC 被 5 塔围死——经济型退化图，STALL 属可接受。
- seed 1006（v4）：双方满编互瞪 5.5M tick（敌 all-in 判定被我方塔值 hdr[55] 威慑，
  我方 OVERWHELM 被敌 4 塔+22 兵挡住）→ v5 诱敌破解。

## v8-v13 关键教训
- v8 远程站桩（弓/投石机不送近战圈）+ 贴脸闪击 closeRush（走廊≤14）。
- v9 贴脸图敌兵常驻我警戒圈 → !threat 永假 → 永不反击（1019 实锤）；
  closeRush 豁免 threat 门 → 8/10。
- v10 进攻态压制 DEFEND → 5/10 回滚（家被拆穿）。
- v11 残血回撤回血（HP<100 撤 TC 背侧站桩，>220 归队）+ Stone Mining → 1010+ 10/10。
  回撤是消耗战的核心杠杆（敌 3.07× 产量，老兵=免费替换）。
- v12 战中 gold3 无石工 → 石断供卡死 塔4/5→磨坊→马厩 链 → Easy 1002 七百万 tick
  对峙（军值 115 < OVERWHELM 130 永远不出门）。v13：塔<5 且石<25 时保 1 石工。
- 单局噪声极大：同种子跨版本胜负会翻（敌 rush 时机随菜单导航墙钟相位漂），
  三个版本连续同种子败才是系统性信号。
